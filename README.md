# 🧾 Expense Tracker CLI

A lightweight command-line tool to track your daily expenses and export them to a CSV file.

## 🚀 Features

- Add new expenses with category, amount, and notes
- View expenses from today, past week, or month
- Calculate total spending in each period
- Stores data in a CSV file (`expenses.csv`)

## 🛠 Tech Stack

- Python 3.x
- Built-in `csv`, `argparse`, `datetime`, and `os` modules

## 📦 Setup

```bash
git clone https://github.com/your-username/expense-tracker-cli.git
cd expense-tracker-cli
python3 main.py --help
